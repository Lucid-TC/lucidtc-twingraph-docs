class lucidtc_twingraph.core.twingraph.TwinGraph(twingraph_id, payload=None)

Bases: object

A graph-based representation of a digital twin network.

Internally provides a flexible and high-performance graph structure. A TwinGraph manages a collection of nodes (representing devices, services, or data points) and their relationships.

add_graph_connection(graph_store_node, connection_type='GRAPH_DATASTORE_CONNECTION')

Adds a graph datastore connection node to the TwinGraph.

This method adds a GraphStoreNeo4jNode to the graph, establishes its parent-child relationship with the TwinGraph, and creates a connecting edge.

Parameters:

  • graph_store_node (GraphStoreNeo4jNode) – The graph store node to add.

  • connection_type (str, optional) – The type of connection. Defaults to “GRAPH_DATASTORE_CONNECTION”.

Raises:

ValueError – If a node with the generated twingraph_id already exists in the graph.

add_mqtt_broker_node(mqtt_broker_node, connection_type='MQTT_BROKER_CONNECTION', source_twingraph_id=None)

Adds an MQTT broker node to the TwinGraph.

Connects an MQTTBrokerNode to the graph, sets its parent, and creates a relationship to a specified source node or the main TwinGraph node.

Parameters:

  • mqtt_broker_node (MQTTBrokerNode) – The MQTT broker node to add.

  • connection_type (str, optional) – The type of connection. Defaults to “MQTT_BROKER_CONNECTION”.

  • source_twingraph_id (str, optional) – The ID of the source node for the connection. Defaults to the main TwinGraph node ID.

Raises:

ValueError – If a node with the generated twingraph_id already exists in the graph.

add_mqtt_topic_node(mqtt_topic_node, connection_type='MQTT_TOPIC_CONNECTION', source_twingraph_id=None)

Adds an MQTT topic node to the TwinGraph.

Integrates an MQTTTopicNode into the graph, linking it to a source node. If no source is specified, it attempts to link to its parent broker node.

Parameters:

  • mqtt_topic_node (MQTTTopicNode) – The MQTT topic node to add.

  • connection_type (str, optional) – The type of connection. Defaults to “MQTT_TOPIC_CONNECTION”.

  • source_twingraph_id (str, optional) – The ID of the source node for the connection. Defaults to the parent broker or the main TwinGraph node.

Raises:

ValueError – If a node with the generated twingraph_id already exists in the graph.

clear_edges()

Clears all edges from the internal graph.

This method removes all edges from the graph’s edge list, but the nodes are not changed.

Return type:

List[Tuple[int, int]]

Represents an AI Agent as a node in a TwinGraph.

This class extends TwinGraphNode to encapsulate an AI agent. It extracts the agent’s metadata (name, model, description, instructions) and its associated tools. lucidtc_twingraph.graph_datastores.tools.create_twingraph_from_remote_graph(remote_twingraph_id, graph_store_node)

Creates a TwinGraph object from data from a remote graph datastore.

Connects to a graph datastore, retrieves TwinGraph data for the given ID, creates various nodes and edges, and returns a TwinGraph object. If the process fails, the function returns False.

The function supports TwinGraphNode, MQTTBrokerNode, MQTTTopicNode, and GraphStoreNeo4jNode node types. Each node is configured and added to the TwinGraph with its relationships to other nodes.

Parameters:

  • remote_twingraph_id (str) – The ID of the remote TwinGraph to retrieve.

  • graph_store_node (GraphStoreNeo4jNode) – The GraphStoreNeo4jNode object to use for connecting to the graph datastore.

Returns:

A TwinGraph object with the retrieved data on

success, otherwise False.

Return type:

TwinGraph | bool

Raises:
